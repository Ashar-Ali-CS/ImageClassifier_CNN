


# CIFAR-10 Image Classifier (CNN) 

This repository contains a PyTorch implementation of a Convolutional Neural Network (CNN) trained on the CIFAR-10 dataset. The project was iteratively improved using GitHub Copilot Agent as part of a Sparta Global AI Fundamentals  Assignment.

## 📌 Project Overview
- **Objective:** Improve a baseline CNN pipeline to achieve 75-80% test accuracy on CIFAR-10 using an Agent. 
- **Framework:** PyTorch & Torchvision
- **Agent Used:** GitHub Copilot Agent in VS Code
